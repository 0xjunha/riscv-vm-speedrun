# RISC-V Instruction Set Manual

This directory contains pinned excerpts from the upstream
[RISC-V Instruction Set Manual](https://github.com/riscv/riscv-isa-manual).
The manual defines the architectural behavior of RISC-V instructions; the
task-specific execution environment and supported subset are defined in
[`rv32im-eei.md`](../rv32im-eei.md).

The included sections are:

- [`rv32.adoc`](src/unpriv/rv32.adoc): RV32I base instruction set
- [`m-st-ext.adoc`](src/unpriv/m-st-ext.adoc): integer multiplication and division
- [`preface.adoc`](src/unpriv/preface.adoc): specification versions and status

The complete published specifications are available from
[RISC-V International](https://riscv.org/specifications/).
